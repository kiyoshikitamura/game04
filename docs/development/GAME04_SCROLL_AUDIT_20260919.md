# GAME04 スクロール監査・修正

基準SHA: 50c7b95d0810357e983ed819cd14a89a2095bee4
対象: GAME04 dev Preview。DB、ゲームルール、報酬、課金仕様は変更なし。

## 原因

html/bodyがoverflow:hiddenで固定される旧レイアウトに対して、新rd-shellはmin-heightだけでスクロール領域を持たなかった。Home、育成、Raid、Battle結果などの長いページは画面外の要素へ到達不能だった。
スクロールバーは画面別に色・幅・非表示指定が分散し、個別のcustom-scrollbar指定がない領域へ共通適用されていなかった。

## 適用範囲

|対象|対応|
|---|---|
|Home／育成5タブ／Raid一覧・詳細／Battle・結果／Gacha・Shop|rd-shellを100dvhのスクロール領域化。フッター余白・safe-area・画面切替時先頭復帰|
|Questエリア・ステージ一覧|既存内部スクロールを維持し、共通デザインへ統一|
|Quest・Raid情報／出撃準備／確認ダイアログ|中央80dvh・本文minmax(0,1fr)・内部スクロール・操作欄折返し|
|Home切替／Community／任務ダイアログ|本文スクロール、ヘッダー・操作欄の縮小防止|
|キャラ・Skill・装備詳細／Battle詳細・分析表|既存スクロールへ縦横共通バー適用|
|設定／お知らせ／プレゼント／認証／ガチャ演出・結果|継承コンポーネントのflex・高さ制約・内部スクロールを個別監査補正|
|起動／名前入力／認証／法務|短画面でのスクロール補正、既存法務スクロールへ共通バー適用|
|横スクロールタブ等|旧scrollbar非表示ルールを共通方針で上書き|

装飾の画像clip、HPゲージ、非公開の旧PvP/Guildロジックは変更しない。

## 確認

型・Buildと公開Previewでの代表的な長いページ／ダイアログの末尾到達を最小確認する。全端末・全OSの網羅受入は後工程。
