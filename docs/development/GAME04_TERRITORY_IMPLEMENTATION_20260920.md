## 受入条件と検証記録

以下は検証予定であり、PASSの申告ではない。

| 対象 | 必要な確認 | 結果 |
|---|---|---|
| 導線 | アイテム0でもトップへ遷移、開始だけ不可。理由/入手方法表示 | 未検証 |
| 開催 | レベル不足/枠満杯で部分消費なし。同時開催は上限内、同request再送同結果 | 未検証 |
| 主催者成長 | 中間Lvは経験値なし、最終クリア時2勝なし/3勝一度付与 | 未検証 |
| 確定順 | 最終討伐の3勝目を含める。クリア後の遅延3勝目は遡及なし | 未検証 |
| 他者クリア | 主催者不在でも自動付与、救援者には経験値なし | 未検証 |
| 並行クリア | 同一主催者の複数侵攻で加算欠落なし/各侵攻一度 | 未検証 |
| 枠/解放 | クリア/時間切れで枠解放、未受取保持。Lv上昇で枠/対象解放 | 未検証 |
| 固定版 | 開催後Master更新で期間/敵/報酬/クリア経験値不変 | 未検証 |
| 既存回帰 | 個別勝敗/3勝報酬/非遡及/Lv強化/旧Lv精算/中央スクロール | 未検証 |
