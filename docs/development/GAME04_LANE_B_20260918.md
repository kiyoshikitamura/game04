## Story（#56 #57 #58）

`src/domain/quest/progressionGuide.ts` に7章×3段階×開始/クリア＝42場面、126発言を制作。元の章前後14場面から3倍に増加した。旗を掲げた城主が、道と暮らしを守りながら諸将と約束を重ね、天下分け目へ向かう創作本編。

場面は `id / townId / stage / phase / speaker / image / lines` を持つ独立データ。戦闘設定を増やさずに場面と発言を追加できる。既存60体の武将名と戦国立ち絵を使用。会話背景には提供済みの城前背景を仮当てし、新規素材待ちにしない。

クエスト選択画面で当該ステージ開始と、クリア済み段階の未読場面を順に表示。初級・中級のクリア後場面は、報酬画面を閉じて同じ章を開いた時に表示する。戦闘中は表示しない。既読は `game04-quest-story:v1:<user-id>` に場面単位で保持し、上級クリア後は既存RPCの章既読も更新する。ブラウザを変えた場合、場面既読は再表示される（従来と同じローカル既読方式）。保存不可でも進行を妨げない。話者・本文・立ち絵・次へを既存Dialogに接続。場面変更時に行位置をリセットする。
