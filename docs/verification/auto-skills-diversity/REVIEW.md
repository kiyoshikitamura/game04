# おまかせスキル：編成全体の重複抑制（2026-09-27）

基準：PR #37 / work/game04-common-preview-20260925 / e5852ea。

## 原因と変更

従来は各武将へ同じ「LB降順→消費SP降順」の先頭候補を渡し、編成内の採用済みスキルを参照していなかった。全員が同じ補助スキルになる選択方針を置換した。

- スキル種ID単位で編成全体の使用済み集合を管理。別LB・重複所持レコードを別種として扱わない。
- 全員の1枠目→2枠目→3枠目の順で、未採用候補と武将の組合せを評価。未採用種を使い切った後だけ残り枠で共有を許可。同一武将内の同種重複は引き続き禁止。
- 攻撃効果の有無を第1優先、その後は効果量・範囲・持続・確率、武将属性との一致、パッシブP06/07/10/12/13との対応、現在ATK、LB、レアリティ、常時発動条件を評価する。条件付きSSRも候補に残す。
- 評価点は選択専用の静的指標であり、実ダメージ予測や戦闘計算への補正ではない。属性一致も選択上の好みであり、新たな属性一致ダメージボーナスではない。
- 同点はレアリティ→固定スキルID→編成位置。所持配列順・乱数・現在のスキル装着順に依存せず、再実行で結果を維持する。
- 鬨の声の個別除外なし。手動装備、マスターの効果・消費、バトル/BURSTは変更なし。

現行所持モデルは `{id, level}`（解放済み種とLB）。個体数を消費する装備ではなく、同じ所持スキルの武将間共有が可能。重複獲得は既存素材変換を保持。未知の保存済みIDは所持から削除せず自動候補からのみ除外する。重複レコードのLBは戦闘と同じ先頭レコードを参照する。
