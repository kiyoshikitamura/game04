## 判断サマリー

- 採用済みの敵43面273項目・確定配布A44箇所を実マスターへ実装。既存報酬を保持し、必要面の前で確定取得する。周回報酬は変更なし。

- 5段階比較は **66/68面**。別攻略・技能個別非依存・保存済み編成の停滞まで含めた計算上の比較条件を満たすのは **38/68面**。全68面合格ではない。
- 未達は30面。**28面に300行動到達が残る**（元の14面中11面＋追加探索で確認した17面）。加えて1-1・5-4に不足段階が残る。全て面別JSONに証拠と次の処置を保存した。
- 1-2〜1-5・2-1は、採用配布技能を個別に使わない到達前資産の攻略を確認。1-1の免除は複数戦法だけで、5段階不足を免除していない。

## 攻略性の変更

序盤1-2〜1-5・2-1・2-2と5-2・5-5・6-3は、HPだけを下げて勝たせる方式ではなく、敵HP/ATKを増やした入力で技能の配置・攻撃順を変えた。武将Lv/覚醒・装備は各面の5帯で同一。技は到達前の所持資産の中から選び、未育成技はLB0で比較した。早い火力投入、通常攻撃でのSP供給、強化/回復の配置によって勝率が分かれる。

9-6・10-6・10-8は敵HP/DEFの調整とATK圧力の組合せ。主・別攻略を残しつつ、低勝率側が300行動まで生き残る膠着を避ける。全保存検証編成で300行動が出なかった入力のみ実装した。未知の全編成や全seedでの非停滞を保証するものではない。

3-5・10-5は代表4編成では改善したが、5帯を追加すると別編成で停滞したため実装採用しなかった。3-2などは戦闘が短すぎて別攻略の中核が発動しない候補も棄却した。改善例1つを面全体の解消と扱っていない。

## 試行条件と限界

約60%は50〜70%、約30%は20〜40%、低勝率は0%超〜10%、全勝/観測0勝は試行上の値。基本の独立確認は200試行で、探索用12/24試行とはseedを分離した。探索で全勝でも独立試行で全勝にならない候補を残している。200/200や0/200を理論上の100%/0%とは主張しない。

新規検証は入力の変化または不足証拠を対象とし、回収済み118,200試行・787候補、8-5修正、既存の25候補5,380試行を保持。入力の戦闘部分が一致する旧証拠は再利用した。失敗seedの診断再生と実再生時間測定は新たな勝率試行数に含めない。

属性効果・攻撃順・実発動した技・バースト回数を保存した。異なる攻略の集約は「実発動した効果種別/対象が異なる」ことを最低条件とする。全68面の因果的な寄与分解や実機での操作理解までを検証済みとはしない。
