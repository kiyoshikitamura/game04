## MVP採点

与ダメージ40・撃破20・回復20・シールド15は各 `round(本人値 / 味方内最大値 × 配点)`、最大値0なら0。最終HP>0で生存5。合計→与ダメージ→撃破→characterIdの順で同点処理。

damage/healingは保存analysis、撃破は保存フレームのHP変化、シールドは新規付与量を使用。複数DOT等で帰属が確定しない旧記録はMVP不可と表示し推測しない。数値カウント420ms、reduced-motionでは即時表示。戦闘再計算なし。
