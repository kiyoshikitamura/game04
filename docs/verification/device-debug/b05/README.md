## 限定ケース

検証用数値は合否境界を作るための入力で、正式マスター/難度へ適用していない。全ケースseed=1。メモリ上の調査器は毎回、未加工engineの結果と同一であることをassertしている。

|条件|結果|
|---|---|
|使用可能スキルあり|各行動で使用、5行動終了。半額の端数切上げも確認。|
|SP不足|半額500SPに対し200SP。通常攻撃5回、SP200/ゲージ0のまま終了。|
|途中でSP0|20SPスキルを半額10で30→20→10→0、その後通常攻撃2回。合計5。|
|条件・対象・優先順位|低HP条件未達、回復対象なしを不採用。使用可能な最上位を選択。使用可能でも下位なら不採用。|
|所持だが未装備|所持スキルを維持して装備だけ外すとbuildBattlePartyの候補0。通常攻撃で継続。|
|5行動到達|5回で終了。BURST内SP/ゲージ獲得0。|
|敵全滅|BURST3行動目で敵HP0→終了。余った2行動は実行しない。|
|行動者死亡|BURST1行動後の敵割込みで死亡→終了。|
|行動不能|1行動→敵stun→**resumeカットイン**→stun_skip→interrupted→end。最後のBURST表示に対応する攻撃はない。終了自体は仕様どおり。|
|終了直後|ゲージ0。次の通常行動で初めて獲得再開。|
|正常な再充填後|複数回BURSTの間に通常行動で200到達を確認。開始時200→0。独立開始をresumeと別集計。|
|エリア1assist|通常獲得2倍/成功80%でもBURST内獲得0・5行動・半額を維持。|

保存実戦5戦では計9回開始、開始表示41回（8回×5行動＋最終1行動）。終了は5行動完了または敵全滅。独立再発動の前にはいずれもゲージ再充填がある。実戦1-5最後のBURSTは1行動で敵全滅、正常終了だった。
