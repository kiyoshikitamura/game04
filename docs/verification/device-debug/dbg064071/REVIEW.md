## 原因と修正

- DBG-064：画面は `game04_update_own_profile` を呼んでいたが、現行共通Previewの隔離DB `znakrkaazliexzwihxge` には当該関数が0件。旧devには存在。現行DBへ本人専用RPCを反映。privateの権限昇格処理はauth.uidで本人1行に限定し、公開wrapperはinvoker、anon実行不可。名前8文字/自己紹介200文字・既存の日次変更契約・同値再試行を保持。未搭載の称号所有機能を勝手に許可しない。wallet/所持品は変更しない。
- フロントは設定パネル内エラーを表示し、失敗時編集内容を保持。編集開始時に最新値を取込み、再保存時に旧エラーをクリア。
- DBG-071：旧BagTabは存在するが現行RedesignShellメニュー・RedesignAppの描画分岐から欠落。メニュー→所持品と5分類を復元。既存共通行/タブ/詳細を使用。
- 現行所持量はRedesignState、召喚券は本人user_itemsを参照。questTicketGrantsは累計であり残高に使わない。従来のuser_items素材/旧育成素材は保管品として残し、換算・合算しない。未受取プレゼントは含めない。武将/スキル/装備への導線も保持。
- 使用は既存use_energy_drink。主アプリの正式応答と報酬更新イベントに追従。券/保管品読込失敗は空表示と区別し再試行可能。

## 限定検証

- 実DB：専用匿名QAユーザーで実HTTP保存成功。実ブラウザで1回の通信失敗を注入→入力保持→再試行→保存成功→ページ再読み込みで保存値一致。201文字拒否・保存値不変・同値再試行も確認。
- 実API：shop_exchangeで活力丸2個獲得、同requestId再試行で重複付与なし。実ブラウザで1個使用し個数−1/行動力＋50、再読込一致。

- 純粋投影テスト：獲得、消費、JSON再読込、旧素材分離、券累計の非加算。
- セキュリティ：本人RLS SELECTを確認、RPC anon不可/authenticated可。新規テーブル/広範なusers更新権限付与なし。Advisors確認済み（既存指摘の全体是正は今回範囲外）。
