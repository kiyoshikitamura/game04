## 提案

1. 一覧用の短い達成条件名（16px）。CSS省略・説明文の流用はしない。
2. 進捗バー＋現在/目標＋残回数。達成時は満了バー＋「達成」。あと0回/受取可能を併記しない。
3. 正式報酬アイコン・数量＋右に挑戦/受取。受取済みは小さいチェック。

報酬は先頭2件、残りは＋N件。個別アイコンも＋N件も44px以上の操作領域で名称・正式数量を確認できる。3段行は自然高、余白8px・行間2px・薄い区切り線。通常109px、固定高/省略で切らない。

選択タブは受取可能→進行中→受取済み。受取済みは末尾に折りたたみ。タブには受取可能件数。下部の一括受取と閉じるは固定、本文のみスクロール。0件無効、受取中は一括/単独/タブ/閉じるを無効化する。

## 実任務との対応

formalMissions.ts/JSONの正式マスターを生成時に読み込む。短名をIDで明示定義し、選んだ任務は正式名のまま1行に収まるため恣意的に短縮しない。対象はデイリーDM002/005/007/008/003/006、ノーマルNM001〜006の抜粋。全文長文の架空任務は作成しない。名称/条件/報酬をmission-data.jsonに保存。正式マスター・数量の変更なし。

- DM005「出陣で3回勝利」：銭2,000、装備EXP小3、侵攻令1（＋1件から確認）。
