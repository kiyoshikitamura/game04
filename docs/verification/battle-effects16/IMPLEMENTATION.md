## モックの継承

- enemy/allyは対象IDが記録のpartyに所属するかで決める。使用者側は使わない。
- 単体は各モックの画面幅比。全体斬撃は元の41/49%の各斬撃幅×100%、全体衝撃は元の個別幅×100%、全体回復は敵47/66/47%・味方27%の光×100%。全体サイズを一律のCSS幅に変換しない。
- 斬撃の8コマと可変間隔、飛び道具の4×2コマと位置補正・最終コマ保持、スタンの4×3コマ、各レイヤーの移動・拡大・不透明度・合成方式を継承。
- 全体斬撃は7回、全体衝撃は8個・120ms間隔・560ms拡大、全体回復は70msずつ時間差。回復の十字は複数の小さな十字を含む透過画像をそのまま使用。
- 14のHTMLには敵用7回シーケンスのみ存在し、味方切替プリセットがない。幅・角度・Y位置差を保持し、X位置を実対象の左→右順へ対応。7回目は中央の対象。5/6人でも実際の対象のみを使う。
- 全体衝撃の散布位置は対象群の中心を基準にモックの位置差を保持する。
- 04/06/11のHTMLのCSS終端括弧欠落、および一部HTMLの壊れたJSタイマーは実行せず、描画値・キーフレームを有効な専用CSS/再生時計へ移植した。
- SPD上昇・暗闇・沈黙は描画部品を提供。ゲームのスキル型、状態付与、マスター、計算エンジンには変更なし。
