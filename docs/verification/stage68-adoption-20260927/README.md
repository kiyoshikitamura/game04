# GAME04：敵・配布・停滞の採用判断資料

## 判断サマリー

- **条件付きで推奨**：敵43面273項目の既存案と、攻略前の確定配布A（前面44箇所）を一組で審査する。敵の変更はHP/ATK/DEFで、技能・行動条件は保持する。既存の2攻略と中核技の実発動、同資産の低勝率/順序比較を対応付けた。数値緩和だけで攻略性を証明したとは扱わない。
- **配布の理由と影響**：確定技・装備・育成資源を必要面の前に持てるようにする。追加武将0、既存報酬の削除0。後半58面では主/別で使う技能を1つずつ外した30%以上の保存例が到達前資産A内にある。6-4の水断なしは103/200（51.5%）で、従来の「約60%」帯内だが強い代替の余地がある。全技能同時除去や全戦法の保証ではない。序盤1-1～1-5・2-1には技能を外した資産内証拠が不足しており、44配布案とは分けて残す。
- **停滞案は全面採用を推奨しない**：14面で敵1体のHP削減とDEF緩和＋ATK増加を比較。10-8のWave2/位置2のDEF 2940→2499、ATK 2329→2911は限定改善候補。対象低勝率編成の300到達160/200→0/200、主200/200、別195/200。ただし別の5/200・旧次点の33/200はまだ停滞し、旧次点の勝率も83.5%へ変わる。面全体の解消として採用できない。10-6も対象低勝率は短縮したが、旧次点86/200が停滞するため保留。
- **承認対象**：敵43面の値、配布A44箇所、採用する局所停滞差分、1-1限定の複数戦法例外。全て未承認。1-1でも5段階記録は免除しない。共通300上限・共通式・BURSTの変更は今回提案しない。UIは補助案として別承認。
- **採用後に残るもの**：到達前資産条件付き5段階充足9面／残59面を維持。採否待ちだけで不足帯の証拠は埋まらない。14面の停滞は全て面全体として未解消。採用入力に対する不足帯、技能なし代替、実再生時間、統合実装・実機受入・G5が残る。
