# 採用境界・実装引継ぎ

## 1-1限定例外（未承認）

例外対象は1-1の「異なる戦法を必須にする」条件だけ。初期確定所持品で操作を学ぶ導入面として提示し、戦闘開始、属性表示、攻撃順、技能条件、BURSTの操作を学べることを実機で確認する。初回報酬やガチャ取得を初戦の前提にしない。5帯の実測・不足記録は残し、全勝記録を理論100%としない。

通常の複数攻略・同程度資産の比較評価は**1-2から**開始する。他面へ自動拡張しない。正式承認までは1-1の未達を維持する。前回READMEにあった「複数戦法/5段階の対象から外す」は、この今回案では採用しない。旧資料は履歴として保持する。

## 敵・技能依存

43面の変更量はHP62、ATK154、DEF57、計273項目。`enemy43.json`の`enemies.changes`を適用候補とし、before一致を必須とする。行動・技能条件・SP・形態は前後同一。`TACTICS43.md`で対象・効果・配置・実発動を確認し、未発動技や武将名の変更だけを異なる攻略の証明にしない。属性/BURSTそれぞれの寄与を完全分離する要因実験までは実施していない。

後半58面に特定技なし30%以上の保存例があることは、技能を単独で外せる証拠である。複数技能を同時に外しても成立する保証ではない。6-4のSKD008なし51.5%は「約60%」の探索帯50～70%には入るため、5帯不足と混同しない。依存表の60%以上という追加目安を正式基準にしない。

序盤は1-1 SKD003、1-2 SKD003/SKD039、1-3/1-4 SKD003、1-5/2-1 SKD039の資産内除去例が未確認。異なる戦法の存在と、両戦法に共通する技の不要性は別問題。`skill-dependency.json`に資産外の置換例、必要技1個、追加育成差分、前面配布候補を保存した。これらは44箇所Aに含めていない別案であり、まず現行資産での順序/対象変更候補を使い、足りなければ敵個別調整または早期の代替技配布を別承認する。1-1は前面がないため初期所持変更の別承認なしに配布で解消しない。

## 配布A44箇所

`supply44.json`の`currentFirstRewards`がbefore、`additions`が差分、`proposedFirstRewards`が合成後。既存数量を置き換えず追加する。表の`grantOn`初回クリア受領後、`requiredBefore`の開始前に入手する。既存反復報酬は変更しない。同面の初回報酬を攻略前提にしていない。

追加量：技24種各1、N/R装備40個、技素材755、汎用R魂180、銭2,800,500、武将EXP1,251,300、装備EXP1,555,100。追加武将0。面別の既存報酬との差分・量はSUPPLY44.md。銭/EXPを削るBは追加2,711成功周回・行動力16,695を要する非推奨履歴であり、追加検証なし。

運営影響：既クリア者への遡及・未受領報酬の扱い・二重配布防止・資源供給増の経済影響は承認時に決める。初期資産/残高/EXPを黙って移行しない。課金商品価格や有償限定経路は追加しないが、無償供給増による入手価値の変化は運営判断が必要。UIは報酬内容表示の追従が必要。既存報酬kindの利用を想定しており新DBスキーマを要求する案ではないが、実環境へのマスター/配布反映・冪等性検証はデバッグ統合担当の範囲。

## 停滞の採否

14面はUIでは閉じない。旧主攻略は全14面で300到達0だが、別攻略または約60%攻略にも停滞がある。敗北側だけと確認できたのは保存対象の9-1だけであり、未探索全編成への一般化はしない。

10-8の限定候補は`stall-tests/10-8.json.gz`内`local-defense-85-attack-125`。43面案に対する追加差分で、正式値に直接掛け算しない。主200/200、別195/200、中核技実発動を確認。対象低適合0/200勝・停滞0/200・行動P90 238。旧次点は167/200へ上がり33件停滞するため、この候補を採用するなら次点帯を取り直す。旧5帯充足をそのまま新入力へ持ち越さない。

10-6はDEF3269→2779、ATK4473→5591。主/別200/200、対象低適合0/200・停滞0だがP90 267、旧次点114/200のうち86件が300到達。保留。9-3・9-6にも独立200試行の失敗を保存し、他10面は12seed選定を通過しなかった。失敗候補を大量適用する実装パッチは作成していない。

継続順：採用する敵入力を面単位で固定→未達帯/技能なし代替を同資産で限定検証→停滞した上位攻略を含む行動分布を確認→実クライアントの通常再生/倍速/SKIPの時間を計測。共通300上限変更なし。将来共通ルールが必要になれば全68面・保存戦闘snapshot・再生互換性への影響を明記して別承認する。
