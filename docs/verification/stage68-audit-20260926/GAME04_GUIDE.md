# GAME04 全68ステージ攻略ガイド

改訂：2026-09-26／監査基準 PR #37 d804d2a、実配信19c8f28、API v8。

**全68面を現行エンジンで検証。入手条件込みでは成立10面・条件付き58面。全iPhone実機クリアや全育成経済の受入合格ではありません。**

固定した具体編成で60または200seedを評価し、主条件5,480試行・5,470勝。不安定な7-8/8-3は別200seedも追加しました。詳細は [全68面の検証済み条件](GAME04_ALL_STAGES.md)、[監査表](AUDIT_TABLE.md)、[問題と承認待ち調整案](ISSUES_AND_PROPOSALS.md)。旧ガイドの敵Lv由来の目安を推奨条件として使わないでください。

3-1は初期5名を指定順に置き、全員Lv25/覚醒0、WEAPON_009を各1個Lv20/LB0、技034/038/010/009/039を各LB3で200/200勝。これは最低値ではなく検証済み条件です。武器と一部技の取得はガチャ依存です。Lv20・120%技への変更だけではDBG-047の防御を突破できません。

## 読み方

- 全68面は5／5／5／5／6／6／8／8／10／10面。ファイル名 `quest65.json` は旧名称のままだが中身は68面。序盤追加3面を含む。
- ステージごとにWave数が異なる。一律6Waveではない。
- 「検証済み条件」は固定入力での複数seed検証です。条件付きの面ではガチャ品・覚醒・素材を満たしているか先に確認し、未所持の場合の推奨と読み替えないでください。
- 主力や対策技は所持済みなら利用。ガチャに存在することと確定入手は区別する。終盤の初期R編成クリアを保証しない。
- 各面の敵スキル名は正式表示名に統一し、敵専用倍率・SPはステージに保存された値を使う。プレイヤー用LB0値とは異なる。

## 編成・戦闘の基本

1. 味方は配置順に行動する。対策・強化を先、攻撃を後へ置くのが基本案。ただし敵割込みとSP不足で予定通りには進まない。
2. スキルは装備順に使用可能なものを選ぶ。通常行動はスキル不可なら通常攻撃。消費SPは5人共通で上限400。
3. 通常攻撃の基本SP獲得20、能動スキル10にLUK補正。BURSTゲージは別で上限200。三河1-1〜1-5には獲得2倍・BURST確率80%の序盤補助がコード上存在する。他面へ一般化しない。
4. 新BURSTは使用可能な攻撃スキルを持つ武将が対象。最大5行動、攻撃スキルのSP消費なし。通常攻撃・回復のみ・補助のみを連発するものではない。BURST中はSP/ゲージ獲得なし。敵全滅・本人死亡・行動不能等で終了し、次Waveへ残回数を繰り越さない。
5. 攻撃技のない武将はBURST抽選をせずゲージを次へ渡す。攻撃役へBURSTを寄せたい場合、低火力の支援役へ無目的に攻撃技を追加しない。
6. ダメージ属性は攻撃スキルの属性。武将自身の属性は被ダメージ相性、通常攻撃、パッシブ等に関わる。同属性の武将に同属性スキルしか付けられないわけではない。
7. 火→風→土→水→火が有利1.5倍、逆が0.75倍。光と闇は相互に有利1.5倍。光/闇の有利攻撃は被ダメージ増加も確認。
8. 単体回復はHP50%以下。全体回復は生存味方の半数以上がHP60%以下で対象成立。回復は術者ATK依存のため、回復役の武器も重要。
9. 破勢＝ATK/DEF強化解除。破護＝シールド/継続回復/反撃/挑発解除。奮起＝能力低下解除。浄毒＝継続ダメージ解除。解縛＝行動不能解除。解除カテゴリを混同しない。
10. 覚醒0はスキル1枠、+1で2枠、+3で3枠。キャラLv上限は50→60→70→80→90→100。複数枠案を未覚醒武将へそのまま装備できるとはしない。
11. 高倍率主砲を低消費技より後の枠に置くと、低消費技が常時優先される。主砲を先に置いてもSP不足が続くなら、他の消費役を減らす。
12. バトルは自動進行。攻略手順は編成・装備・配置によって狙う順序であり、プレイヤーが任意のタイミングで技やBURSTを手動発動する説明ではない。

## 入手・育成の考え方

通常ガチャの正式プールに各候補が含まれることは照合済み。排出は確率なので「その面までに必ず揃う」とは書かない。初回報酬の武将/装備EXP素材と銭を、攻撃役の武器・被弾役の耐久・回復役のATKへ集中する。必要EXP・銭・覚醒魂・LB素材・前面までの確定供給・周回案を各面に追記しました。実アカウントの所持や進捗は変更していません。指定品の抽選入手・無課金到達日数は保証しません。

|負け方|最初に見直すこと|
|---|---|
|先頭が即死|HP/DEF装備・敵攻撃属性・威圧や防御強化|
|回復役だけ落ちる|最後尾指定攻撃、回復役を2番目などへ移す|
|回復が出ない|HP発動条件、共有SP、上位スロットの優先技|
|敵HPが戻る|後列回復源の処理、継続回復なら破護|
|BURSTで自滅|敵反撃の解除と発動者の耐久|
|硬い敵が削れない|武器ATK・単体倍率・敵DEF強化/シールド・鎧砕き|
|長期戦で崩れる|回復/解除を維持しつつ攻撃2役、Wave間の残HP|

## エリア別入口

- [1. 三河の地](GAME04_ALL_STAGES.md)：初期3人から5人へ。加入と配布スキルを実際に装備し、通常行動とBURSTを学ぶ。
- [2. 尾張の旗](GAME04_ALL_STAGES.md)：複数敵と支援役の処理。単体・全体・後列狙いを使い分ける。
- [3. 美濃の城](GAME04_ALL_STAGES.md)：弱体・強化・継続ダメージを主力攻撃に接続し、共有SPの使い道を絞る。
- [4. 近江の湖](GAME04_ALL_STAGES.md)：集中被害と全体被害の双方に対応。回復だけに偏らず攻撃枠を残す。
- [5. 甲斐の山](GAME04_ALL_STAGES.md)：属性とパッシブの組み合わせを見直す。武将の受ける相性とスキルの攻める相性を分ける。
- [6. 越後の雪](GAME04_ALL_STAGES.md)：毒・能力低下・行動不能への対策枠を選ぶ。解除の種類を合わせる。
- [7. 京洛の影](GAME04_ALL_STAGES.md)：敵の能力強化と保護を区別して解除。解除後に主力を動かす。
- [8. 出雲の社](GAME04_ALL_STAGES.md)：連戦でのHP・SP・状態の持越しに対応し、各役割を最後まで残す。
- [9. 薩摩の炎](GAME04_ALL_STAGES.md)：各戦術の専門試験。ステージテーマは唯一の攻略法を意味せず、所持戦力に合わせる。
- [10. 関ヶ原](GAME04_ALL_STAGES.md)：複数の対策を組み合わせる最終エリア。10-8の形態変化と10-10の長期戦に備える。
