# 全68面の修正方針再検討：編成の工夫と複数攻略の両立

2026-09-26 23:02 JST追加指示を反映。正式設定・配信・ユーザー状態は変更しない。旧監査の勝利例は現行計算の証拠として保持するが、新しい設計合格とは区別する。3-1 DEF620案の単独承認依頼を取り下げ、候補の比較からやり直す。

## 採用する基準

1. 通常ステージごとに、考え方が異なる攻略を少なくとも2系統成立させる。敵を弱体化する／味方を強化して攻撃する、後衛を先に処理する／前衛へ集中してBURSTで抜く、解除する／保護の切れる時間まで耐えて攻める等。キャラや属性名だけ変えた同じ手順を2系統と数えない。
2. 少なくとも1系統は到達前の確定入手で構築できる。もう1系統も複数の武将・技で代替でき、両系統に同じ未配布スキルや高レア武将を必須にしない。共有する必須品がないか、片方ずつではなく全ルートの共通部分を検査する。各系統の到達前取得条件も実証する。
3. 同じLv・装備条件と同程度の育成費で比較する。別解だけLv/装備/LBを大幅に上げて通すことを、多様性の証明に使わない。高育成は安定性・時短の利点として残すが、初回到達に高育成を押し付けない。
4. 属性、配置、対象、技能順、共有SP、BURST役の選択が、勝率・行動数・被害のいずれかへ意味のある差を生む。要素を外す比較は、別の役割へ置き換える比較と対にする。対策を単に空欄へするだけでは「他の攻略法がない」と断定しない。
5. 全要素を全ての面で必須にはしない。序盤は個別の学習、後半は組合せ。ガチャ品の所持検査、単一の正解手順、乱数の一点突破を課題にしない。

## 全68面での適用順

- エリア1：既存の加入・技配布・BURST成功体験を保持。単一の演習は確定配布と説明で完結させ、通常攻略のガチャ所持制限へ広げない。
- エリア2〜3：初期配布からの2系統と、育成/入手予算を最初に作る。3-1だけ下げて3-2以降で再び詰まる状態を避ける。
- エリア4〜5：守備・回復・属性のテーマを、対応する技1個の必須チェックにしない。
- エリア6〜7：解除以外の解法を重点確認。特に旧支援除外で大きく崩れた7-8を優先する。
- エリア8：連戦のSP/回復配分と代替役を確認。高い数値だけで継戦できる案に依存しない。
- エリア9〜10：各戦術の得意場面を作るが、テーマ通り以外を締め出さない。9-2/9-5/9-9と、SSR装備依存だった終盤3面を重点対象にする。

前回の初期武将置換が観測95%未満だった面は42面。ただしこれは人物置換の結果であり「解法が1つしかない42面」という意味ではない。全68面について2系統を新たに検証する。

## 修正案を採用するまでの検証

各面の到達予算 → 異なる2〜3系統 → 武将/技の置換 → 同育成の属性/配置/順番/SP/BURST比較 → 独立seed評価 → 前後面の連続到達と供給確認、の順に行う。採用候補は原則各系統200seedで評価し、勝率だけでなく敗因、行動数、防御突破、SP不足、300行動待ちを比較する。

観測95%以上は戦闘の安定目安であり、多様性・入手・経済の合格とは別。複数経路の共通必須品、片方だけの極端な費用、時間切れの多発が残れば数値案を差し戻す。3-1の試験だけで全68面を合格にしない。

成果表は「到達育成予算／攻略A／攻略B／共通必須品／置換候補／攻略操作の効果／勝率・行動数／変更フィールド」を各面1行で示す形式へ拡張する。承認済みの報酬減額、BURST旧仕様への復帰、共通Previewへの先行適用は行わない。

## 3-1での追加検証：単一攻略を避ける方向の具体例

旧620案は同じLv20/覚醒0/装備なし/技LB2の20seed探索で、防御低下20/20、攻撃強化9/20、継続ダメージ0/20だった。620を採用すれば多様性が成立するとは確認できなかった。

上の「別属性」は攻撃強化系統の置換例であり、3つ目の独立系統とは数えない。全ルートを鎧砕きの所持で縛る必要はなく、配布済みの鬨の声・岩断を使うルートも戦闘上成立した。岩断は同じ所持技を2武将へ装備でき、2個の抽選獲得を要求しない。

ただし確定入手なのは攻撃強化ルートの武将/技IDまで。LB2まで含めた到達保証は別問題。攻撃強化ルートの育成費は銭77,550、武将EXP59,550、技素材18。先の限定固定供給集計は銭89,500、武将EXP59,500、技素材16で、素材2等の差がある。未計上の到達済み任務、他ルートの技入手、過去消費を含む連続進行を照合してから採否を決める。必要なら選択式の攻略支援報酬案を別途提示する。
