## 4. 超過算入の数値比較と適用境界

過去の実操作記録 `docs/verification/g2-20260924/qa-e/FINAL.md`：TI01 Lv1、敗北8、勝利1の個人damage23,992、勝利2の個人damage24,063、共通HP70,000。**TI01 Lv1は抽選編成であり常にHP23,040ではない**。今回正式マスターで再確認した該当候補は `4-2/3`、前田慶次、個人HP23,040、共通HP70,000。`random=0.5`でその候補を固定したローカル比較である。

|比較|現行：超過込み|推奨：実HP減少のみ|
|---|---:|---:|
|1勝目の基礎算入|23,992|23,040|
|1勝目の勝利倍率後|35,988|34,560|
|敗北8＋1勝後の共通残HP|34,004|35,432|
|2勝目の勝利倍率後|36,094（24,063×1.5切捨て）|34,560（全HPを倒し切る場合）|
|敗北8＋2勝後|Lv1突破、Lv2へ|Lv1残HP872|
|Lv1報酬資格|2勝なので報酬なし|次の3勝目で突破なら、その勝利を含む資格判定が可能|

推奨でも3勝資格の保証は追加しない。他者の攻撃や他の編成では資格前突破があり得る。表は特定保存事例の比較であり全編成への保証・勝率予測ではない。

実装時は「合計damageを開始HP合計で一括cap」ではなく、攻撃・反撃・DOTごとのHP減少量を記録する。回復・蘇生で同じHPが再度減る場面を正しく数えるため。多段演出を二重算入しない。shield吸収を実HP減少へ含めない。既存snapshotと過去結果を再計算せず、新しい開催の明示的なルール版を追加する。共闘に同じ変更を自動波及させない。
