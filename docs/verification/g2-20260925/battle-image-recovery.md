# G2 継続 U04/U06: 戦闘画像失敗時の復帰

基準: `79669373df0af1a586d0b00cc56b4a3dcb9b1ec9` / PR #30。変更SHA・統合Previewは親の統合記録を参照。

## 問題と修正

`BattleView` の画像読み込みが失敗すると、native modal に再試行しかなく、永続的な画像欠損では画面から離脱できなかった。背面の操作は遮断され、戦闘中は共通ナビゲーションも非表示となる。

`src/app/components/redesign/BattleView.tsx` に、現在の戦闘・画像集合の読み込み失敗時だけ「再生を終了する」を追加した。既存 `onComplete` を一度だけ実行して復帰する。通常出陣では保存済み settlement の結果表示へ、共闘/侵攻と未完了戦闘の再開では親の既存復帰経路へ進む。API は再生開始前に決済済みであり、この導線は戦闘開始・消費・報酬付与を呼ばない。独立レビューで復帰先が経路ごとに異なることを確認し、結果画面を約束しない共通文言へ修正した。

再試行を選んだ瞬間に loading へ戻し、旧エラーの復帰ボタンを残さない。別の result / imageKey の失敗を現画面のエラーに使わない。通常時の SKIP 表示・権利、倍速、戦闘計算、共有HP算入、保存済みsnapshot、API/DBには変更なし。CSS変更なし。
