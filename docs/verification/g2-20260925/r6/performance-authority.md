# G2 R6 承認済み性能基準

2026-09-25。最新ユーザー承認により、従来の性能基準判断待ちを解除する。以下は目標案ではなく受入基準。過去の少数試行・代替環境観測を遡及して合格へ変更しない。

|対象|開始→終了|承認基準|試行条件|
|---|---|---|---|
|cold|キャッシュなしURLアクセス→主要情報表示・操作可能|5秒以内|独立したcold条件5回、全回達成|
|warm画面遷移|タップ→主要情報表示・操作可能|1秒以内|操作ごと20回中19回以上。残1回も基準の2倍以内|
|保存・受取・交換|確定タップ→結果表示・次操作可能|1秒以内|操作ごと20回中19回以上。残1回も基準の2倍以内|
|戦闘開始|出撃確定→再生開始|3秒以内|操作ごと20回中19回以上。残1回も基準の2倍以内|
|タップ反応|タップ→押下または処理中表示|0.1秒以内|表示終了・API終了と分離して記録|

## 1.5秒例外

warm遷移と保存系に限り、改善しても1秒達成が難しい箇所へ1.5秒の例外を適用できる。対象箇所・実測値・実施した改善・残る要因を記録する。20回中19回以上、残1回も適用基準の2倍以内という条件を保持する。cold、戦闘開始、タップ反応へ例外を拡張しない。改善未実施・未測定を理由に一括例外扱いにしない。

## 対象環境・測定の分離

- 主対象は **iPhone Safari**。WiFi と 4G/5G を別条件で記録する。端末・OS/ブラウザ・回線・キャッシュ・対象SHA/API版・操作を残す。
- cloudブラウザ・エミュレーション・デスクトップ・ローカル代替測定は、iPhone Safari実機受入と区別する。
- API待ち、画像待ち、主要情報と操作可能までの時間を分離。同一条件で変更前後を比較する。
- Google／Stripe の外部サービス内の待ち時間はゲーム内の基準と別記録。ゲームへの復帰処理はゲーム側受入対象。
- 既存の2フレームCTA観測は対象CTAの観測値であり、主要情報の完全表示・正しい残高・全必要操作の完了を自動証明しない。

## 結果区分

各対象・各条件の結果は **合格／1.5秒例外適用／未達／未測定** のいずれか。回数不足、条件未統制、実機未実施は対応する未測定範囲を明記し、静的試験やAPI単体時間でUI受入を代替しない。

R4/R5の保存済み観測は原因分析・変更前資料として保持する。この文書の作成だけで既存観測を新基準合格と判定しない。
