## 残差・未受入

1. **貢献パネルとCTAの桜・和柄装飾は専用候補素材で接続済み、承認は未了。** `panel-sakura-overlay.png` の薄い桜・和柄を最終下部画像で確認した。モックと花の図柄・配置が完全一致するものではなく、接続確認を素材承認へ読み替えない。
2. 新規背景1点、UIアイコン9点、丸属性6点、桜・和柄オーバーレイ1点の**計17点は未承認候補**。モックと図柄、質感、線の細かさ、色・透過の見え方が異なる。明度を調整したことは素材承認を意味しない。詳細は `docs/design/raid/2026-09-23/WORK_ASSET_MAPPING.md` を参照。
3. 一覧のHPから時間行までの余白は縮小したが、モックと同一画素の一致を確認したものではない。Headerの顔の切り取り、個々の文字寸法・余白・装飾も完全一致とは判定しない。
4. **390px／1536pxのレイアウト、スクロール下部、長い正式名称や異なる人物の全組合せは未検証。** 既定幅の結果を他の幅へ外挿しない。
