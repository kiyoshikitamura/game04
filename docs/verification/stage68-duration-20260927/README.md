## 実時間の比較

同じ編成・seed・3倍速・再開から最終フレームまでの実測。旧値は基準SHAの記録を保持して引用。計算実装とBattleViewは同じ版で、敵入力のみ異なる。

|面|seed|実秒 前→後|行動 前→後|このseedの結果|
|---|---:|---|---|---|
|10-3|532112|201.09→115.10|297→161|勝利→全滅。低勝率編成の長い勝利例を短い敗北へ変更|
|7-7|581155|176.87→134.72|295→218|全滅→勝利。終盤の耐久軽減で突破|

単一seedの結果変化と勝率評価を分ける。各入力200試行の主・別攻略は全勝を維持。対象例の改善であり、全編成の一律短縮ではない。

追加代表は保存ログ62面から抽出した2面だけを測定した。8-7は回復121イベント・294行動で **222.52秒**、2-5は全体技74回・BURST10回・257行動で **158.47秒**。この2面は敵入力を変更していないため改善前後の比較はなく、今後の時間面の判断材料とする。行動数から秒へ換算していない。

既報の2-3 **216.86→113.01秒**、10-4 **221.09→65.16秒**、9-6 **178.21→65.52秒**は無変更で保持。

武将/装備の育成量は面内で同じ。技能は到達前資産から選び、主・別攻略で用いる各技能を個別に使わない成功攻略も確認。別攻略は実発動する効果種別/対象が異なり、回復系だけの差を採用していない。中核発動数、BURST、到達前状態、編成順は面別JSONに記録。
