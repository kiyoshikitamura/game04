## 視覚確認

390pxの通常／スキル命中／BURST、360px通常を最終配信で照合。画像欠落・ドキュメント横はみ出し、命中数値・技名・HP同期、行動者とカットインを確認する。取得済みの最終画像および配信IDは `browser-verification.json` に記録。

QAのframe操作欄を含むiframe撮影では下端が一部画面外となる場合がある。スクロール可能なQA撮影範囲と、本体の欠落を区別する。比較画像の人物・数値・ロゴは既存正本素材／再生記録を使用し、モックの架空数値や人物一致を合格条件にしない。

## 未確認／残件

- 認証付き実DBの出陣／共闘／侵攻の開始・報酬確定。
- 画像／名称が正式未対応のv2スキルは効果種別アイコンで表示。新規正式素材の確定は別タスク。
- SPD・暗闇・沈黙は現行v2戦闘イベントが無いため、実戦接続済みとは扱わない。
