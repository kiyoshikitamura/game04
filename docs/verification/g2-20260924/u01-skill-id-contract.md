## 旧資産保持と判断

- 旧50IDの所持、LB、編成は独立catalogに保持。旧ガチャpool/初期付与は変更していない（G3/G4）。
- 過去戦闘snapshotは変更・再計算しない。新たなSKD取得のみ正確なLB行で戦闘入力を組む。
- 推奨：旧IDの変換を行わず、72IDを独立した所持資産として追加。旧資産の今後の扱いは実DB集計後に判断。番号対応、同名だけによる変換、Lv/EXP換算はしない。
- 実DB集計（2026-09-24、読取専用）：state 40件、SKILL_001〜008各40所持＝320行。旧user_skills 12ID/27行。旧growthVersion未付与かつLv>1またはEXP>0は武将0/装備0。詳細は u01-live-asset-counts.json。2テーブルの行は同一資産を含むため347個と合算しない。
- 名称：上表の設計名称を全72件採用する案と、世界観に合わせ別名を採用する案。数値・IDには影響なし。
- 画像：既存50画像の意味を個別照合して流用可能候補を確定し、不足のみ制作する案を推奨。未照合画像の順番割当はしない。現時点で72行の正式画像承認が必須未完。
