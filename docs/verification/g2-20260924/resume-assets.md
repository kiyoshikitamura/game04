## 72画像について既存候補を失わない

`src/theme/local-skills.json` は **72 designId / 72行 / 50画像path** の既存候補対応を持ち、50画像pathは全て基準Git treeに存在する。各行にsourceId/sourceName/path/basisがある。新たな72件制作を即断する前にこの表を利用できる。

ただし、basisは「属性違い等は共通画像を再利用」「旧スキル効果との同一性を意味しない」であり、正式SKDの画像採用承認にはならない。例: SKD002水の単体攻撃候補が弓取りの一射、SKD004風が疾風の足運び。名称だけで攻撃図柄の適合を断定できない。本確認では画像実物の視覚採用審査は行っていない。

現在 `PreparationModal.tsx` は `sourceId === skill.id` に限定してこの表を使い、正式SKD IDを旧IDへ変換しない。この制限を外すと未承認候補が本体へ入り込むため変更しない。正式採用後はU01の同一72行へ画像path/採用根拠を記録してMaster側へ接続し、別の画像件数として二重計上しない。
