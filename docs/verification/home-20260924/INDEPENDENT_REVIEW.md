## 接続担当の実API記録レビュー

`live-api.json` と `scripts/verify_game04_home_live_api.mjs` を独立担当が読取確認。
GAME04 dev API v18、既存使い捨てQAに限定した次の実行結果を確認した。独立担当による再実行ではない。

- 武将・背景の同時保存と `get_state` 復元。
- 同一requestId再送で選択とversionが不変。
- 旧2IDと既存正規2IDの保存・再読込。
- 未解放背景＋別武将の同時変更を原子的に拒否し、保存値とversionが不変。
- 不正背景ID・未所持武将の拒否。
- 編成・育成・所持品・銭・輝石・出陣進行の保持。
- 検証後は元の表示へ復元。元が未設定だったため、キー不在への復元ではなく同じ表示になる既定値の明示保存と記録している。

これは認証付き実APIの証拠であり、ブラウザ操作→描画→再読込の証拠を代替しない。
