# GAME04 バトル UI・演出ビジュアルモック要件
日付：2026-09-24
状態：ユーザー承認済み。初回モック生成前に保存。
Repository：kiyoshikitamura/game04

## 目的・進行
敵を大きく見せながら「誰が・何をして・どう変わったか」が演出とUIの両方で分かる戦闘画面にする。
全体検証は最後にまとめる。今回は要件保存とビジュアルモック生成。実装・mainマージ・Production変更は行わない。
参考：ユーザー添付 IMG_2807.jpeg。構図・迫力の参考であり正式データではない。
既存統合成果を保持し、本資料保存コミットへ実装コード全体を巻き戻さない。

## 1. 画面構成
| 領域 | 要件 |
|---|---|
| 上部 | 現在Wave／総Wave、既存の速度・AUTO等の操作 |
| 敵情報 | 敵ごとの名前・Lv・属性・HP・行動までのカウント・状態変化 |
| 中央 | エネミーを大きく配置する主戦場。攻撃・被弾・回復・状態変化 |
| 味方情報の直上 | 共通SPとバーストの状態・操作 |
| 下部 | 編成順の武将カード。HP、状態変化、スキル情報、現在の行動者 |
| 背景 | 対象ステージに対応する正式背景 |

- 敵の単体・複数構成ごとに画像占有率を調整する。
- 敵の顔・HP・行動カウントを他の敵や演出で隠さない。
- 味方最大5人を基準に、3人などの途中編成も成立させる。
- 戦闘情報・操作に領域を優先。参考画像下部の宣伝コピーは配置必須にしない。

## 2. 行動の分かりやすさ
1. 行動者：該当する味方カードまたは敵を発光・強調。
2. 行動内容：通常攻撃／スキル名を短く表示。
3. 対象：対象の敵・味方を枠や明暗で強調。
4. 発動・命中：対応エフェクトと被弾反応。
5. 結果：ダメージ・回復数値、HP変化、状態アイコンを同期。
6. 次の行動：強調を解除して次へ移る。

演出より先にHPが減る、数値が別の敵に見える、前のスキル名が残る表示を避ける。
倍速でも順序と結果の読み取りを保つ。

## 3. 別制作する共通エフェクト16系統
| 系統 | 用途 | 視覚表現 |
|---|---|---|
| 単体斬撃 | 刀・短刀・連刃系 | 鋭い斬線・斬痕。連撃は命中に合わせ反復 |
| 全体斬撃 | 大旋風・乱舞系 | 敵陣を横断する斬線・旋風。各対象の命中を明示 |
| 単体打撃 | 拳・金砕棒・大槌系 | 一点への衝撃・破片・短い被弾反応 |
| 全体衝撃 | 地裂・範囲打撃 | 全体へ広がる衝撃波・地裂 |
| 射撃・飛び道具 | 弓、毒針、火薬玉 | 発射方向・飛翔・着弾がつながる |
| 単体回復 | 手当、薬、祈り | 対象を包む光・上昇粒子・回復数値 |
| 全体回復陣 | 金創膏、神医の陣 | 味方全体を覆う陣と各対象への回復光 |
| ATK上昇 | 攻撃強化 | 赤・橙の上昇オーラ＋剣の記号 |
| DEF上昇 | 防御強化 | 青・金の防壁＋盾の記号 |
| SPD上昇 | 速度強化 | 黄緑の風・残像＋速度の記号 |
| ATK低下 | 攻撃弱体 | 暗赤・紫の下降演出＋剣の下降記号 |
| DEF低下 | 防御弱体 | 防壁の亀裂・装甲破砕＋盾の下降記号 |
| 毒 | 毒付与 | 紫／黄緑の毒煙・滴 |
| 暗闇 | 暗闇付与 | 対象を覆う黒煙・遮光 |
| 沈黙 | 沈黙付与 | 封印札・封印紋 |
| スタン | スタン付与 | 短い衝撃＋星・電撃 |

- 色だけで区別せず、形・動き・記号も変える。
- 付与時の演出と継続中の状態アイコンを分ける。
- 毒など継続効果の発生時も原因と結果を示す。
- 単体／全体の対象範囲を正しく反映。
- 付与不成立時に成功演出を出さない。
- この16系統は演出素材の分類。新たなスキル効果・ゲーム仕様を追加しない。

## 4. バースト
発動可能・発動操作・発動中・結果を通常行動と明確に区別する。
- 発動可能時は操作部を発光させるなどして知らせる。
- 発動時は「バースト」と専用開始演出。
- 発動者と作用先を明示。
- カットインを使う場合、命中・結果を見せるタイミングで解除。
- 発動後のSPや状態変化まで連続して見せる。
発動条件・消費・効果・操作方式は既存正式仕様に従う。
参考のSP 68/100やBURSTボタンから仕様を決めない。共通SP上限は確定済み400。
バーストとSPの因果関係・消費量をモック側で創作しない。

## 5. 素材・意匠
- 参考は敵の大きさ、戦場の迫力、味方カードの並び。
- 参考内の人物名・属性・数値・スキル数・Wave数を正式仕様へ採用しない。
- GAME04正式の武将・敵・背景・属性・スキル・既存UIアイコンを優先。
- 新規制作は主に16系統の演出と不足するバースト演出素材に絞る。
- エフェクトは背景と一体化せず対象位置へ重ねて再利用できる素材にする。
- 金・黒基調の既存UIへ統一。装飾で情報を圧迫しない。
- 回避・Criticalなど正式仕様にない判定を演出都合で追加しない。
- モック内の描画は正式素材の採用承認を意味しない。

## 6. モックで用意する状態
| 状態 | 確認内容 |
|---|---|
| 通常戦闘・複数敵 | 敵の大きさ、個別HP、行動カウント、味方情報 |
| 単体ボス | ボス占有率、情報配置、背景 |
| 通常攻撃／スキル命中 | 行動者・対象・効果・数値・HP |
| 回復／強化／状態異常 | 効果の違い、付与対象、継続状態 |
| バースト可能／発動中／命中後 | 操作の認知と演出の流れ |

モックに開始→命中→結果の順序を添える。静止画の発光・カットインを常時表示として実装しない。
初回生成は方向性確認用。全状態や16系統の素材制作完了とは扱わない。
