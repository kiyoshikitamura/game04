# バトル演出素材・スキル対応表（2026-09-24）

## 実装
- BattleEffects.tsx / BattleEffects.module.css：背景と分離した16系統のSVG/CSSオーバーレイ。対象ユニット内に配置。
- battleEffectPresentation.ts：記録フレームの成功eventを分類。付与不成立を成功表示しない。
- 原画の人物や文字を切り出した素材は使用しない。既存武将・背景はBattleView側で利用。
- 全体技の対象はサーバーが記録したtargetIdsに従う。対象別フレームを勝手に同時化しない。
- 通常攻撃は単体斬撃。武器未指定の技は単体/全体斬撃を表示上の既定値とする。武器攻撃判定の追加ではない。
- スキル名に弓/矢/射/針/火薬/鉄砲/銃/弾/投げ/飛道具がある場合は射撃、拳/槌/棒/打撃/衝撃/地裂/砕/震/轟は打撃へ分類。対象範囲は正式effect.targetを優先して検出する。

## 16系統の素材

|系統|形・動き|接続|
|---|---|---|
|単体斬撃|斜めの白い斬線・拡大|damage/counter|
|全体斬撃|横断斬線と弧・横移動|damage/counter + 全体target|
|単体打撃|放射状衝撃・短い拡縮|damage/counter + 打撃名|
|全体衝撃|衝撃輪・放射地裂|damage/counter + 全体target/打撃名|
|射撃飛び道具|飛翔線・矢尻・遅れて着弾輪|damage + 射撃名|
|単体回復|十字と上昇粒子|heal/revive/hot|
|全体回復陣|二重楕円陣と回復光|heal + 全体target|
|ATK上昇|剣と上向き矢印|atk_up追加差分|
|DEF上昇|盾と上向き矢印|def_up追加差分|
|SPD上昇|風線と速度記号・横移動|素材のみ。現行v2に対応効果なし|
|ATK低下|剣と下降矢印|atk_down追加差分|
|DEF低下|割れた盾と下降矢印・振動|def_down追加差分|
|毒|毒煙と滴・上昇|dot/poison追加差分、dot発生|
|暗闇|黒煙と遮光した眼|素材のみ。現行v2に対応効果なし|
|沈黙|封印札・円紋|素材のみ。現行v2に対応効果なし|
|スタン|星と電撃・左右振動|stun追加差分|
