## 3. 素材不足・未接続の扱い（必須）
以下を区別する：
- Gitに存在するがBranchにない → 固定取得元から必要差分を取り込む。
- 実装に存在するが参照していない → 表示経路を接続。
- 対応表がないが割当権限はある → 既存素材で割り当て、対応表を保存。
- 正式名称・効果・必要素材そのものがない → 未定義／不足として対象を明記。
- 正しい参照だが見えない → CSS、透明余白、表示倍率、重ね順、配信経路を調べる。

禁止：旧GAME03画像、無関係な属性画像、全身画像への無断退避、絵文字、仮のCSS枠、架空の名称・効果、引き延ばしや過剰クロップで不足を埋めること。
既存資産で表現できる旗・位置番号等のCSS装飾は可。実画像が指定された枠・属性・アイコンをCSSだけの代用品にしない。
真に不足している場合、該当箇所は未完成として残す。全作業を止めず独立した修正を完了し、必要な判断だけを一括で提示。未完成画面を「完成」として配信報告しない。
新規生成・元画像再加工は無断で行わない。明智光秀のバトル画像1件は供給待ち、未使用SSRサンプルの割当禁止を維持。

## 4. カードを共通部品として完成させる
描画順：武将ごとの固定背景 → 用途に合うキャラ → GAME04レアリティ枠 → 小さい属性・レアリティ・位置表示。文字とCTAを装飾で覆わない。
- 背景は既存マイページ背景10種から各武将60体へ割り当てる。割り当てはユーザー承認済みの作業権限であり、各件の再承認は不要。
- 対応表は武将ID→背景ID→ファイルパスでGit管理。選択中のHome背景を全カードへ流用しない。同じ武将は画面間で同じ固定背景を使用。
- カード用画像、汎用ポートレート、全身、バトル用ディフォルメを使い分ける。
- 枠は/creative/ui/frame-{N,R,SR,SSR}.png、正方形はsquare-*の実素材を確認して使用。旧getRarityFrameAsset呼出しを残さない。共通関数の全用途を無条件に置換せず、GAME04表示経路を統一する。
- レアリティ文字が素材に含まれるか確認し、巨大バッジの重ね・二重表示をしない。正しい独立バッジがなければ既存枠内表示や承認済み文字表示で判別させ、旧バッジを流用しない。
- 属性は正式6属性画像を意味まで一致させて使い、同一カードに大・小2回表示しない。
- 枠と人物は共通の基準矩形で重ねる。人物の透明余白を含むファイル寸法ではなく実際に描かれた人物の見え方を調整する。
- 名前・Lv・HP等は必要な文字サイズで表示。SRは控えめな光、SSRはより豪華な光・枠演出。複数カードは一斉点滅を避ける。文字・操作を妨げず、低減モーション・非表示タブでは停止。
- 静止画だけで演出確認済みとしない。SR/SSRの動作は短い動画または再現手順と実操作で確認する。確認のためにMasterや所持データを改変しない。

Home背景演出は選択背景に紐付き、レアリティ非依存。背景解放はクエスト全10エリアの解放に連動。カード固定背景とは別管理。
今回はクエストと共有部品の是正が対象。Home等のページ固有の未接続は別行で記録し、無断で全ページ改修へ拡大しない。共通部品を変更した影響は確認する。
