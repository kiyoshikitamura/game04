## 分離範囲

World Introductionから名前入力・送り出し、初回出陣誘導、ログイン表示、初敗北誘導までの専用確認環境。
通常のGameProvider/bootstrapを呼ばず、認証セッションの保存キーと進行テーブルを分離した。
GAME04 dev `lrgyllgzcdcphlbmkknc` の新規 `game04_tutorial_preview_states` だけに進行・所持品・編成を保存する。
このテーブルは本人のみ読み書き可能なレビュー用snapshotであり、クライアント編集が可能。正式な報酬・所持品の権威には使わない。
本体へ統合するときは、同じ遷移と固定付与を認証済みサーバーアクション・既存台帳に接続する。既存プレイヤーの初期資産を置換する実装ではない。

通常の任務、商店、雇用、共闘、交流は専用環境から実データに接続しない。チュートリアル由来のボタンロック解除と任務への遷移を確認できる。
出陣・育成の確認には既存画面と計算処理を使い、結果は専用snapshot内に保存する。確認用行動力100は配布仕様の変更ではない。
名前は既存UI同様1〜8文字。専用snapshot内に保存し、正式アカウント名は変更しない。

## 戦闘

既存BattleViewに専用記録を渡す。通常戦闘エンジン・1-1・報酬マスターは変更していない。
伊達の仮ステータスはLv1 / HP50 / ATK1 / DEF0。確定した固定ダメージを優先する。
基本攻撃3回で各1、紅蓮の大計で味方全員に各50、次の北条ターンで確定バーストし、土割りを3回各20。
伊達HPは50→49→48→47→27→7→0。最後の表示は20。累計表示63・実HP減少50。
画像失敗による戦闘スキップを防ぐため、BattleViewに任意の `requirePlaybackCompletion` を追加。通常戦闘の既定動作は維持する。

## 保存と再開

画面遷移・付与・編成を単一行の更新で保存。revision比較で別タブからの古い書込みを拒否する。
同一遷移の再送・古い画面からの遷移は追加付与しない。保存失敗時はその画面に留まり、再試行／再読み込みできる。
模擬戦中の再読み込みは模擬戦の先頭から再生する。戦闘報酬や1-1のクリアは付与しない。
確認メニューから最初に戻れる。
