# GAME04 チュートリアル確定要件

保存日：2026-09-25（JST）／版：v1

本会話でユーザーがFIXした構成・文言・登場武将・初期付与・模擬戦・背景・終了後導線を統合した保存版。仕様確定の記録であり、実装・配信・実機受入完了を意味しない。
対象Repository：kiyoshikitamura/game04。GAME03は変更しない。

## 1. 全体構成

1. World Introduction 3画面。
2. 豊臣秀吉が登場し、案内を開始。
3. 仲間の必要性を説明し、固定武将3人を直接付与。
4. 武将のビジュアルと「仲間になった」表示で獲得を明確にする。
5. 技の重要性を説明し、固定スキル3つを直接付与。
6. スキルアイコンと「手に入れた」表示で獲得を明確にする。
7. パーティ編成・スキル装備の必要性を説明し、おまかせ操作で指定の編成・装備を行う。
8. 模擬戦とSP・バーストを説明。
9. 伊達政宗との専用チュートリアルバトルを実施。
10. 勝利後、豊臣の案内で初めて名前を入力。
11. 入力した名前を豊臣の送り出し文に反映し、終了。
12. 初回マイページから出陣へ誘導。

チュートリアル中はガチャを行わない。開始時には名前を入力させない。模擬戦はメインクエスト1-1とは別の専用戦とする。
案内役は豊臣秀吉で確定。豊臣の案内はチュートリアル終了まで。終了後のダイアログは豊臣のセリフではなく通常口調で説明する。

## 4. 専用模擬戦

### 敵と基本方針

- 敵は伊達政宗1体（ID：char_leo_01）、Lv1。
- HP50。ATK・DEFはかなり低く設定する方針。具体値は未指定だが、ダメージは以下の専用固定制御を優先するため戦闘進行に依存させない。
- 所持スキルはSSR「紅蓮の大計」（SKD025、火属性の全体攻撃）。
- 既存バトルUI・演出を使用する。
- 専用戦に限定して行動順・ダメージ・SP・バースト・撃破タイミングを固定する。通常戦闘や正式スキルの共通性能は変更しない。

### 固定進行

|順序|行動|ダメージ|伊達残HP|
|---|---|---|---:|
|開始|伊達政宗登場|—|50|
|1|北条氏康が通常攻撃|伊達へ1|49|
|2|井伊直政が通常攻撃|伊達へ1|48|
|3|お市が通常攻撃|伊達へ1|47|
|4|伊達が「紅蓮の大計」で全体攻撃|味方3人それぞれへ50|47|
|5|次の北条のターンで確定バースト、土割り1回目|伊達へ20|27|
|6|バースト中、土割り2回目|伊達へ20|7|
|7|バースト中、土割り3回目|伊達へ20|0・撃破|

- 味方3人の攻撃でSPが貯まり、次の北条のターンで確定バーストに入る。
- 土割りは1スキルの3ヒットではなく、別々のスキル発動を3連続で見せる。
- 最新FIXは「通常攻撃1、バースト中の土割り20×3」。以前の「味方の与ダメージは一律1」は土割りに適用しない。
- 3回目の土割りまで敵を生存させ、3回目で撃破して終了する。最終攻撃の表示ダメージは20、HP下限は0。
- 回復・バフを模擬戦中に見せるための追加行動は入れない。「応急手当の発動を見せるための調整」という途中提案は撤回済み。
- 終了後は豊臣の勝利セリフ→名前入力→送り出しへ進む。

## 5. チュートリアル終了後

|タイミング|確定挙動|
|---|---|
|初回マイページアクセス|ログインボーナス画面を表示しない。出陣以外のボタンを非アクティブにし、出陣を促すダイアログを表示する|

|その後|日付切り替わり後にログインボーナスを表示する通常運用|

終了後の説明は通常口調。豊臣は登場させない。初敗北時の説明は一度のみとする。
ログインボーナスについて今回確定したのは表示タイミング。既存の付与・日次重複防止と整合させ、表示抑制を根拠に報酬の二重付与・消失を起こさない。

## 7. 実装・確認時の引継ぎ事項

会話で確認した実装上の成立条件：

- 途中離脱・再読み込み時に進行を再開できること。
- 武将・スキルの固定付与を二重実行しないこと。
- おまかせ後の編成・スキル対応と名前を保存すること。

- 初回マイページ、2回目のログインボーナス表示、出陣後のロック解除、初敗北案内の一度限りの状態を正しく扱うこと。
- 背景の実ファイルパスと武将素材を既存Gitから照合し、World Introductionの配置はGAME03を参考にすること。
- 通常バトル、既存ガチャ、既存ユーザーの所持・進行を専用模擬戦の固定処理で変更しないこと。

構成・主要仕様・文言・画像指定は確定済み。未指定のレイアウト細部、低いATK/DEFの具体値等は確定済みの進行を成立させる実装調整として扱い、新たなシナリオ・導線・付与・演出段階を独自に追加しない。
