# GAME04 スクロールUI共通ルール

2026-09-19 ユーザー指示。全ページ・ダイアログに適用。

- 画面より長い内容は、末尾の説明・ボタンまで必ずスクロールできる。
- メイン画面のスクロール所有者は `.rd-shell`。高さ100dvh、縦スクロール有効。html/bodyの旧アプリ用固定と両立させる。
- デザインスクロールバーは金色のthumb／暗色track、縦横共通。スクロールバーの非表示・幅0は禁止。実装は `src/app/scroll-policy.css`。
- 一覧・本文・横長表・タブも共通スタイルを適用。実際にスクロールする領域には高さまたは幅の制約を持たせる。
- 長文ダイアログは中央、最大約80dvh、本文はmin-height:0かつoverflow:auto。固定ヘッダー／操作欄は縮めず、本文を内部スクロールする。
- 一体型カードはカード全体を内部スクロールし、先頭の閉じる操作と末尾のCTAへ到達できること。
- フッター・端末safe-areaに隠れない末尾余白を確保。画面切替時はページのスクロールを先頭へ戻す。
- 画像・HPゲージ・演出の装飾用overflow:hiddenは維持。すべての要素を無差別にoverflow:autoへ変更しない。
- ブラウザー／OSがネイティブバーの常時表示や色を制限する場合でも、指・ホイール・キーボードによるスクロールを妨げない。

新しい画面・モーダルを追加する際も本ルールを適用する。
