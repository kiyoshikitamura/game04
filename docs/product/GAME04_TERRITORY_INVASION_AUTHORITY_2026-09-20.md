# GAME04「戦国姫艶武」領土侵攻 正本

仕様FIX日：2026-09-20。本流スレッドのユーザー合意をAuthorityとする。
状態：仕様FIX／実装未着手／数値マスター未FIX。

本書はUnlock Raidの見せ方・開催導線・主催者成長の最新正本。9/19企画正本14.2、Home UI、Raid UIの該当記述に優先する。その他の戦闘・報酬ルールは維持する。

## 1. コンテンツの位置付け

- ユーザー向け名称は「領土侵攻」。内部のUnlock Raidを利用する攻略コンテンツ。
- 他領地の城を攻略し、制圧報酬を得る。領地所有・内政・継続収益は初期範囲に含めない。
- 特別な開催アイテムを消費して主催する。アイテム種類・必要数・入手方法はマスター設計対象。
- ランキングは初期リリース対象外。

## 2. Home／開催／参加導線

1. Homeのクエスト経過CTAの隣へ、大きな「領土侵攻」ボタンを置く。
2. Homeから領土侵攻トップへ遷移する。ページは既存の「レイドに挑む」画面を基本にする。
3. 対象の城・敵の特徴／難易度・報酬・開催期間・必要領土侵攻レベル・開催アイテム必要数と所持数・開催枠を確認する。
4. 対象・期間・消費アイテムを確認して開催。成功後は作成したレイド詳細へ直行し、共通の出撃準備・戦闘へ合流する。

- アイテム未所持でもHomeから領土侵攻トップへ入れる。開始のみ不可とし、理由と入手方法を表示する。
- レベル不足・開催枠不足の場合も開催条件と不足理由を表示する。
- 自分の開催中の侵攻はトップから「攻略を再開」できる。複数件を区別して選べる。
- レイド一覧は、開催中のEncounter／領土侵攻の一覧とする。参加・救援・再開の入口であり、Unlockの開催訴求や「アンロックに挑む」遷移は削除する。
- 開催した領土侵攻もレイド一覧へ掲載する。一覧の時間順・参加者表示等は既存UI正本を維持する。
- 一覧・詳細・救援通知を含むユーザー向け表記は「領土侵攻」に統一する。
- 終了した侵攻は開催中一覧から外すが、結果確認・未受取報酬の入口と受取権は保持する。

## 3. 二つのレベルを区別

| パラメータ | 意味 |
| --- | --- |
| 侵攻中のボスLv | ルーム内の攻略段階。共通HP討伐で上昇・リスポーンし、次の個別敵の強さに連動 |
| ユーザーの領土侵攻レベル | 永続的な主催者成長。領土侵攻経験値で上昇し、同時開催枠・侵攻先の開催条件に使用 |

個人の途中参加Checkpoint、過去Lvへの巻戻し、追い付き戦闘は設けない。
救援参加者も個別戦闘開始時の共有ボスLvで戦う。

## 4. 領土侵攻経験値

- 最終ボスLvを撃破した「侵攻クリア」のときだけ獲得機会が発生する。途中の各Lv討伐では付与しない。
- 獲得者は主催者のみ。救援参加者には付与しない。
- 主催者自身が、その侵攻全体で個別バトル3勝以上していることを必須条件とする。
- 判定は侵攻クリアの確定時点で行う。最後の討伐を起こす戦闘の勝敗を先に確定し、その勝利を含めて3勝条件を評価する。
- クリア確定後に完了する開始済み戦闘で3勝に達しても、経験値を遡及付与しない。これは「クリア時に条件判定」の境界条件であり、開始済み戦闘自体の結果確定は維持する。
- 条件を満たせば主催者が画面を開いていなくても自動付与する。報酬受取ボタンの押下を条件にしない。
- 同一侵攻の経験値は一度だけ。再送・再ログイン・同時討伐・再集計で重複付与しない。
- 時間切れ・未クリアは領土侵攻経験値なし。既に獲得した途中報酬は維持する。
- 同じ城の再開催・再クリアで、開催ごとに経験値を獲得できる。

## 5. 開催枠・侵攻先の解放

- 「開催数」は同時開催可能数。ユーザーの領土侵攻レベルに応じて上限が増加する。
- 同じ主催者の開催中領土侵攻を横断して枠を数える。Encounterや救援参加は主催枠に数えない。
- 侵攻クリア／時間切れで枠を解放する。未受取報酬が残っていても開催枠を占有しない。
- 高難易度・高報酬の侵攻先に必要領土侵攻レベルを設定する。主催者の開催条件として適用する。
- 救援参加者には領土侵攻レベル制限を設けない。既存の参加人数上限・退出後の再参加禁止・出撃行動力・討伐報酬資格は維持する。
- 開催時にレベル・空き枠・アイテムをサーバー側で判定し、枠確保・アイテム消費・ルーム作成を一体で処理する。失敗時は部分消費や枠残存を起こさない。
- 異なる要求IDの連打・並行要求でも同時開催上限を超えない。同一要求IDの再送は同じ開催結果を返す。
- 開催後は開催時の侵攻先・ルールを維持する。開催期間、最終Lv、敵／報酬／クリア経験値などの参照マスターを開催時の版で固定する。更新で途中の攻略条件を変えない。

## 6. 維持するRaidルール

- 個別バトルにはWIN／LOSEがある。個別敵HPとRaid共通HPは別管理で、倒せる個別敵を攻略する。
- 与ダメージを共通HPへ反映し、個別勝利時に勝利ボーナスを加える。
- 共通ボス討伐→Lvアップ・リスポーン→次の個別バトルの敵強化を維持する。
- 開始済み戦闘は開始時Lvで結果確定し、古いLvのダメージを新Lvへ転用しない。
- Raid全体で個別3勝以上により討伐報酬資格を得る。資格取得前のLv報酬を遡及配布しない。
- 基本3日、最大20人、救援6時間ごと最大3回など、未変更の既定ルールを維持する。
- Bossの見た目段階は維持するが、個人Checkpointに使用しない。

## 7. マスター管理と未FIX数値

以下をコード固定値にせず、正式マスターとして設計する。

- ユーザー領土侵攻レベルの必要経験値表、初期値・上限・既存ユーザー移行値。
- 侵攻先ごとのクリア経験値。
- 領土侵攻レベル別の同時開催上限。
- 侵攻先ID、城・名称、必要領土侵攻レベル、必要開催アイテム・個数、期間。
- ボスLv構成・最終Lv・能力・共通HP・見た目段階・報酬。
- マスター版と開催中ルームの参照版。

価格・確率・経験値量・解放Lv・開催上限値・正式報酬量は本書では決めない。マネタイズ設計から逆算して別途FIXする。経験値閾値の順序、解放先の参照、上限値、開催条件の到達可能性をマスター受入で検証する。

## 8. 開発引継ぎ・受入

今回の変更は仕様正本のみ。次の追加工程を仕様FIX済み・未着手として扱う。

| ID | 作業 |
| --- | --- |
| TI-01 | Home横並びCTA・領土侵攻トップ・開催中レイド一覧への導線整理・名称統一 |
| TI-02 | ユーザー領土侵攻経験値／レベルの永続化・成長表／解放条件マスター参照 |
| TI-03 | 主催枠・必要レベル・アイテムの原子的開催判定、開催時マスター版固定 |
| TI-04 | 最終クリア時の主催者3勝判定・経験値一度付与・終了時枠解放・結果／未受取報酬導線 |
| TI-05 | 領土侵攻の統合受入。正式数値・素材の受入とは分ける |

最低限の受入例：

- アイテム0でもトップへ遷移可能、開始は不可。
- レベル不足・枠満杯で開催不可、アイテムは消費しない。
- 同時開催上限までの並行開催だけ成功し、再送も二重消費しない。
- 各Lv討伐では領土侵攻経験値なし。最終クリア時は主催者2勝ならなし、3勝なら一度だけ付与。
- 主催者の3勝目が最終討伐の戦闘なら付与。クリア後に遅れて確定する3勝目では遡及付与しない。
- 主催者不在でも条件を満たすクリアは自動付与。救援参加者は経験値なし。
- 同じ主催者の複数侵攻が同時クリアしても経験値加算が欠落せず、各侵攻一度だけ付与。
- クリア／時間切れで枠解放、未受取報酬へのアクセスは維持。
- レベル上昇で開催上限と侵攻先が解放。救援参加には領土侵攻レベル制限なし。
- 開催中のマスター更新でルームの敵・期間・報酬・クリア経験値が変わらない。
- 個別勝敗・3勝討伐報酬・非遡及・Lv連動強化・旧Lv精算を回帰確認。
