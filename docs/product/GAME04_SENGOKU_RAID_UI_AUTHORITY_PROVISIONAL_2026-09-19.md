# 1. 対象

リリース初期のレイドトップは2種類。

- エンカウントレイド
- 領土侵攻（内部：Unlock Raid）

ギルドレイドは初期レイドトップには含めず、
将来ギルドページ内に統合する。

---

# 2. レイドトップ

目的：

- 開催中のレイドを探す
- 残り時間を確認する
- レイド種別を見分ける
- 救援中 / 参加中を確認する
- 開催中の領土侵攻に参加・救援・攻略再開する

開催中のEncounter／領土侵攻一覧を縦スクロールで表示する。開催訴求・「アンロックに挑む」遷移は置かない。領土侵攻の開催はHomeから専用トップへ移す。

---

# 3. 領土侵攻の開催導線（Homeへ移設）

領土侵攻トップは既存の「レイドに挑む」画面を基本に、Homeのクエスト経過CTA横から遷移する。
対象の城・敵・報酬・期間・必要レベル・開催枠・アイテムを確認して開始する。
未所持でも閲覧可能。開始条件を満たさない場合は開始だけを不可にする。
開催後は既存レイド詳細へ合流し、共通出撃準備・戦闘を使う。
自分の開催中侵攻への再開、終了後の結果／未受取報酬への入口を残す。
詳細は [GAME04_TERRITORY_INVASION_AUTHORITY_2026-09-20.md](./GAME04_TERRITORY_INVASION_AUTHORITY_2026-09-20.md) を参照。
