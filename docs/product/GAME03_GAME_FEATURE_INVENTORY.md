# GAME04比較用 GAME03ゲーム機能一覧

## 目的

GAME04のゲーム機能全体を決めるため、GAME03／TRIBE NEONに存在する機能を一覧化する。
GAME04欄は最終決定ではない。「要協議」「再設計」はサークル側との合意後に実装する。
GAME03の数値、マスター、スケジュール、演出、用語はGAME04の初期値にしない。

## 参照範囲

- GAME03固定参照：TRIBE NEONコミット `826f8b7`
- 技術概要：`TRIBE_NEON_ENGINEERING_TECHNICAL_OVERVIEW_20260901.html`
- GAME04正本：`GAME04_development_start_handoff_20260902.html`
- 変更途中のTRIBE NEON作業ツリーは判断根拠・コピー元に使用しない

## 分類

- GAME03実装状況：`稼働中`、`段階公開`、`一部実装`
- GAME04暫定分類：`導入済み共通基盤`、`採用方針`、`要協議`、`再設計`、

## 11. 比較・決定手順

1. GAME04のコアループと最上位機能を確認する。
2. 「要協議」「再設計」を「採用」「保留」「不採用」に分ける。
3. 不足するGAME04固有機能を第9章へ追加する。
4. 数値より先に、採用機能同士の依存関係を定義する。
5. 承認結果と承認日を意思決定台帳へ反映する。
6. その後に実装タスクを開始し、GAME03の暫定値は使用しない。
