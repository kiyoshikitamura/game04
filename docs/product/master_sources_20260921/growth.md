## 3. キャラ・装備のLv EXPと銭【FIX】

累計EXP E(L) = 10 × round_half_up( E100 × ((L−1)/99)^2.2 ÷ 10 )。
Lv1は0、Lv100はE100に一致させる。各Lvの必要EXPは隣接する累計値の差分。各区間を独立して丸めて合計しない。
累計必要銭 Z(L) はキャラE(L)、装備floor(E(L)/2)とする。これによりユーザー合意済みの10倍銭表に整合する。各Lvの銭は累計銭の差分で算出する。
Lv育成の銭は到達Lvを上げる際に差分を消費する。途中EXPを入れた時とLv到達時に二重課金しない。操作で複数Lv上がる場合は各差分の合計。

## 4. 通常ユーザーLv【FIX】

初期Lv1、ローンチ時の上限Lv100を採用する。
Lv LからL+1への必要EXPは(L+9)^2。累計EXPはLv1からの整数和で管理する。キャラEXP・装備EXPと共有・相互変換しない。
複数Lv分を取得した場合はまとめて上昇。100到達後に得た分はレベル進行へ加算せず、銭や他EXPへ自動変換しない。上限解放後へ向けた先行蓄積も設けない。

ユーザーLvをキャラ覚醒・LB・Lv上限や戦闘ATK/DEFへ直接連動させる新規制限・補正は追加しない。
ユーザーLvによる体力上限の上昇は設けず、Lvアップ時に体力を全回復する【最新FIX】。固定体力上限そのものの数値・自然回復速度は本書で決めない。

| 繰越EXPの範囲 | アカウント内でキャラ用・装備用の2残高を持つ。同用途の別キャラ・別装備にも使用可能。個体に拘束せず、用途間の変換は不可。 |
| 繰越EXPの使用順 | 同用途の繰越を先に使用。不足分を選択アイテムで補う。繰越だけでの育成も可能。余剰は同用途の残高へ戻す。 |
| アイテム消費 | 指定個数は上限として扱い、必要のないアイテムは消費しない。選択内の小→中→大→特大の順に必要数を使用し、最後の1個の余剰のみ繰越す。実行前に実消費個数を表示する。 |
| 銭不足・素材不足 | 確認表示どおりの育成ができなければ全体を実行せず、銭・素材・繰越EXPを消費しない。自動で到達Lvを下げて部分実行しない。選択量の変更後に再計算する。 |
| 繰越EXPと銭 | 繰越へ移すだけのEXPに銭を課さない。対象の到達Lv差分に対して既存の育成銭を課す。繰越使用でも同じルールを適用し、二重徴収しない。 |
| Lvアップ全回復 | クエスト報酬のEXPを確定してLvが上がった場合、体力を現在の上限まで補充する。一度に複数Lv上昇しても回復を積み増さず、既に上限超過していれば現在値を維持する。 |

体力回復の例：上限100で現在20なら100へ、現在120なら120を維持。1回の報酬で3Lv上がっても300は加算しない。Lv100到達時は回復し、その後Lvが変わらないEXP獲得ではLvアップ回復を発生させない。

EXP処理の例：解放上限まで残り510 EXP、同用途の繰越100、選択した中1個（1,000 EXP）の場合、繰越100とアイテム内410を育成へ適用し、590 EXPを同用途に繰り越す。必要銭が不足した場合は実行前の残高・アイテムをすべて保持する。
