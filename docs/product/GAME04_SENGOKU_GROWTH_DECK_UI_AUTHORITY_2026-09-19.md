# 1. 基本方針

GAME03よりもキャラクター鑑賞単体ではなく、

**現在のデッキ管理が快適であること**
**育成・装備・スキル変更へ素早く到達できること**

を優先する。

パーティ5キャラクターは、バトル・出撃準備・デッキ管理・編成の全画面で、

**左から右へ5体横一列**

を共通表示ルールとする。

---

# 2. ページ構造

育成・デッキ管理内部は上部タブで切り替える。

上部タブ：

1. デッキ
2. 編成
3. キャラ
4. スキル
5. 装備

育成内部の切替にフッターを使用しない。

共通フッターは以下を維持する。

1. ホーム
2. クエスト
3. キャラ
4. レイド
5. ガチャ

---

# 3. デッキ ファーストビュー

現在の5キャラクターを横一列で表示する。

表示：

- キャラ画像
- 名前
- Lv
- レアリティ
- 属性
- HP
- スキル / パッシブ状態を示す最小限のアイコン

パーティ全体情報：

- 総HP
- **合計SP**
- 属性構成

SP表示は「合計SP」に統一し、重複表示しない。

ファーストビューに、各管理画面への重複遷移ボタンは置かない。

代わりに以下を置く。

- おまかせ編成
- おまかせ装備
- おまかせスキル

---

# 4. 編成

5キャラを左から右へ横一列表示。

キャラクターの入替・行動順変更を行う。

所持キャラ一覧には、

- 絞り込み
- 並び替え

を用意する。

---

# 5. キャラタブ

キャラタブのファーストビューは**所持キャラ一覧**とする。

特定キャラの詳細を直接ファーストビューへ固定表示しない。

一覧上部：

- 絞り込み
- 並び替え

各キャラカード：

- キャラ画像
- 名前
- Lv
- レアリティ
- 属性
- Role
- 覚醒段階
- 編成状態

---

# 6. キャラ詳細

キャラ一覧からキャラを選択すると、**画面中央の詳細モーダル**を開く。

キャラ詳細モーダルは育成・装備管理を主目的とする。

表示：

- キャラ小型画像 / アイコン
- 名前
- Lv
- レアリティ
- 属性
- Role
- 覚醒
- 武将の魂
- HP
- SP
- ATK
- DEF
- LUK
- パッシブ
- 装備中スキル
- 装備6枠

操作：

- Lv育成
- 覚醒
- スキル変更
- 装備変更

---

# 7. 全身鑑賞

キャラ詳細内のキャラ画像 / アイコンをタップすると、

**全身立ち絵＋背景のみを見せる別の中央モーダル**

を表示する。

これは育成UIではなく、キャラクターのコレクション・鑑賞要素とする。

育成詳細と全身鑑賞を1画面へ混在させない。

---

# 8. スキルタブ

アカウント所持スキル一覧。

一覧上部：

- 絞り込み
- 並び替え

並び替え候補：

- スキルLv
- レアリティ
- 属性
- 消費SP
- 名前

各スキルから育成へ遷移可能。

---

# 9. 装備タブ

アカウント所持装備一覧。

一覧上部：

- 絞り込み
- 並び替え

並び替え候補：

- Lv
- レアリティ
- LB
- 部位
- 名前

装備育成・分解へ遷移可能。

---

# 10. 一括分解

一括分解は**チェックボックス選択方式**とする。

一括分解開始時：

- 装備一覧を選択モードへ切替
- 各分解可能装備にチェックボックス表示
- 複数選択可能
- 選択件数表示
- 全選択可能

装備中・ロック中装備は選択不可。

分解実行前に中央確認モーダルを表示。

確認内容：

- 分解対象
- 獲得予定CASH（銭）
- 獲得予定装備LB素材
- 分解確定

---

# 11. モーダル共通ルール

GAME04では、育成UIを含む**すべてのダイアログ / モーダルを画面中央表示**とする。

ボトムシート型・画面下寄せ表示を使用しない。

共通ルール：

- 画面中央固定
- 左右余白を確保
- max-height 約80vh
- 内容が長い場合はモーダル内部のみスクロール
- 画面下端へ接触させない
- 中央に浮くウィンドウとして表示

---

# 12. デザインスクロールバー

ページおよびモーダル内部のスクロールには、
ブラウザ標準表示のままではなく**GAME04世界観に合わせたデザインスクロールバー**を使用する。

対象：

- キャラ一覧
- スキル一覧
- 装備一覧
- キャラ詳細モーダル
- 全身鑑賞モーダル
- 分解確認
- その他スクロールを伴う中央モーダル

---

# 13. 不要テキスト

実画面に開発者向け説明文を置かない。

例：

- 「左から行動順」
- 「アカウント資産」
- 「編成順を維持」
- 「ドラッグ想定」
- その他実装意図説明

ルールはレイアウト・表示順・操作で理解できるようにする。

---

# 14. 一覧共通ルール

キャラ / スキル / 装備一覧には、

**絞り込み + 並び替え**

の両方を用意する。

フィルタとソートの統合UIについては今後実機で検証可能とするが、両機能自体は必須。
