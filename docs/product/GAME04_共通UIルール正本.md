## 16. 共通演出（指示本文に基づく）

- SRはカード表面を横切る控えめな光沢。SSRは強めの光沢、枠発光・オーラ・周辺粒子を追加。
- カードごとにタイミングをずらす。粒子は周辺に限定し、顔・名前・数値・属性を隠さない。
- 背景演出とは独立。背景演出は選択背景に紐づけ、表示キャラのレアリティを条件にしない。
- 低減モーション・非表示タブで停止。
- 育成、覚醒、魂からの武将獲得は処理成功・結果確定後に中央Dialogへ表示。変更前→変更後、変更後を最大にする。実際の消費・数値・獲得内容のみを表示。
- 覚醒段階と実際の解放内容、魂消費と獲得武将を表示。結果側を光・粒子で強調し、演出終了後も結果を残す。右上×なし、下部「閉じる」。
- CTAはタップ直後に反応し、無効CTAは操作不可。行動力回復等の解消導線は維持。回復後に自動出撃しない。

## 17. 読み込み・表示準備・操作遮断（指示本文に基づく）

- CTA以外の処理もスピナーを表示。複数CTAでは操作対象か中央1か所のみ。初期表示・画面遷移は共通ローディング。
- 長い読み込みはGAME04ロゴ付きへ移行。GAME03既存実装を読み取り参照し、GAME03へは書き込まない。
- 現在の画面/Dialogに必要な画像だけを読み込み・デコードして一括表示。未表示詳細・別ページは対象外。Webフォントの端末フォントfallbackを維持。
- 画像失敗・タイムアウトは成功扱いにせず、再試行案内。永久スピナー待機にしない。
- 処理中・Dialog準備中はHeader/Footer/他CTAを含め全体を操作遮断。表示後はDialogのみ操作可能。再試行案内は操作可能。装飾アニメーションは遮断理由にしない。
