# 1. クエストUI基本フロー

クエストUIは以下の4段階に分離する。

1. エリア一覧ページ
2. ステージ一覧ページ
3. ステージ情報ダイアログ
4. 出撃準備ダイアログ

画面遷移：

**エリア一覧**
→ **ステージ一覧**
→ ステージタップ
→ **ステージ情報ダイアログ**
→ 「挑戦」
→ **出撃準備ダイアログ**
→ 「挑む」
→ **バトル開始**

ステージ情報と出撃準備を1ダイアログへ統合しない。

---

# 2. エリア一覧ページ

目的：

**攻略する地域を選択する。**

表示：

- エリア名
- エリア背景画像
- 攻略中 / クリア済 / 未解放
- 現在攻略中エリアの強調
- 縦スクロール
- デザインスクロールバー

エリアは縦方向へ追加可能な構造とする。

月次シーズンで新エリアが追加されてもレイアウトを変更しない。

ステージ詳細、Enemy詳細、報酬詳細はこの画面に表示しない。

---

# 3. ステージ一覧ページ

選択したエリア内のステージを縦方向に表示する。

表示：

- エリア名
- エリア背景画像
- ステージ番号
- ステージ名
- 消費行動力
- クリア済 / 未クリア / 未解放
- 最新挑戦可能ステージの強調

ステージ進捗は横方向に並べない。

ステージ数追加に対応できるよう、**縦スクロール型**とする。

Enemy詳細・報酬詳細は常時表示しない。

---

# 4. ステージ情報ダイアログ

役割：

**何に挑むかを確認する。**

ステージ一覧ページ上にダイアログとして表示する。

独立ページにはしない。

表示：

- ステージ番号
- ステージ名
- Wave数
- 消費行動力
- 出現Enemy
- Enemy名
- Enemy Lv
- Enemy属性
- 初回報酬
- 通常ドロップ
- レアドロップ

操作：

- 挑戦
- 閉じる

「挑戦」で出撃準備ダイアログへ進む。

ここでは自パーティ編成詳細を表示しない。

---

# 5. 出撃準備ダイアログ

役割：

**何で挑むかを確認する。**

ステージ情報ダイアログの次に表示する。

独立ページにはしない。

自パーティ5キャラを**左から右へ横一列**で表示する。

左→右をそのままバトル行動順とする。

各キャラクター表示：

- キャラ画像
- 名前
- Lv
- 属性
- HP

スキル最大3個を常時並べない。

各キャラのスキル / パッシブは、キャラまたは詳細導線をタップして確認する。

常時表示しない：

- スキル3アイコンの横並び
- 装備
- ATK
- DEF
- LUK
- 個別SP
- パッシブ全文

パーティ全体情報として、

- パーティ共通SP最大値

を1か所だけ表示する。

操作：

- 編成変更
- 戻る
- 挑む

「挑む」で行動力を消費し、Wave1からバトル開始する。

---

# 6. スキル詳細

出撃準備ダイアログ内のキャラ詳細から確認可能。

表示：

- スキル名
- 属性
- 消費SP
- 発動条件
- Target Rule
- 効果

スキル説明全文は出撃準備本体へ常時表示しない。

---

# 7. パッシブ詳細

キャラ詳細から確認可能。

表示：

- パッシブ名
- Lv
- 効果

パッシブ説明全文は出撃準備本体へ常時表示しない。

---

# 8. クエストUIで扱わない要素

以下は本UIへ入れない。

- 時間探索
- 探索時間選択
- 探索回数
- 派遣
- 待機時間
- 星評価
- 推奨総合力
- 「BOSSあり」等の未定義フラグ
- 横方向のステージ進捗
- 出撃準備の独立ページ化
- ステージ情報と出撃準備の混在
- スキル最大3個の常時表示
- 装備6枠の表示
- 手動バトル操作UI
- 作戦設定
- 手動ターゲット選択

---

# 9. 画面前提

- スマートフォン縦持ち
- 9:16基準
- PC横画面を基準にしない
- タブレット横画面を基準にしない
- 横スクロール前提にしない

出撃準備も縦画面内で5キャラ横一列を成立させる。

---

# 10. ヘッダー / フッター

ヘッダーはGAME04共通仕様を利用する。

フッター：

1. ホーム
2. クエスト
3. キャラ
4. レイド
5. ガチャ

クエスト画面では「クエスト」を選択状態にする。

---

# 11. 採用ビジュアル方向性

2026-09-19に承認したUIモックの以下の構造を採用する。

- エリア一覧は背景付き縦カード
- ステージ一覧は縦リスト
- ステージ情報は別ダイアログ
- 出撃準備も別ダイアログ
- 5キャラは左→右で比較
- スキル / パッシブはタップ詳細
- 戦国世界観の背景・金黒基調
- 情報量を抑えつつ、Enemy属性と自編成属性を比較しやすくする
